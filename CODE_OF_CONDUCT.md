# Code of Conduct

mail-autodiscover is a small, single-maintainer project. This document is short on
purpose: it covers the basics of how we expect people to interact here, not a formal
governance process.

## Expected behavior

| Do | Don't |
|----|-------|
| Disagree with the idea, not the person | Insult, mock, or personally attack |
| Give feedback that's actionable | Give feedback that's just critical |
| Accept that maintainer time is limited; a slow or "not now" response isn't personal | Harass or pressure for faster responses |
| Ask before sharing someone else's information | Publish someone's private information without consent |

## Scope

Applies anywhere interaction happens around this project: GitHub issues, pull
requests, code review comments, and discussions.

## Reporting

If something crosses the line, reach **@solarssk** on GitHub (a private message
or a note on the relevant issue/PR works) or use GitHub's
[Report abuse](https://github.com/contact/report-abuse) form for anything that
needs GitHub's own moderation. Reports are handled privately.

## Enforcement

There's no committee here. The maintainer decides case by case, and depending on
severity that can mean asking someone to rephrase, removing a comment, or
blocking further interaction (issue/PR lock, GitHub block) for repeated or
serious violations.
